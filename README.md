# Dulanga — Full-Stack Developer Portfolio (v2)

An ultra-modern, minimalistic, and high-performance single-page developer portfolio built with pure Vanilla HTML5, CSS3, and JavaScript. Engineered with a **Deep Dark Cyber Elegance** aesthetic, ambient mesh lighting, dynamic spotlight card interactions, and interactive engineering case studies.

---

## 🌟 Highlights & Features

- **Cyber Elegance Aesthetic**: Obsidian dark theme (`#07080b`), electric cyan (`#00f5ff`) and neon violet accents, subtle glassmorphism (`backdrop-filter: blur(18px)`), and radial glow mesh.
- **Dynamic Mouse Spotlight**: Linear/Raycast-inspired ambient border tracking that follows the cursor across cards in real-time.
- **Interactive Developer Terminal**: Hero-section interactive terminal simulating realistic development workflows and commands.
- **Featured Works & Case Studies**:
  - **ArcadeWeb**: Gaming & Community Hub (Laravel 11, Blade, MySQL, Tailwind CSS).
  - **Nexus Analytics**: High-throughput SaaS Telemetry & Recurring Billing (Laravel, PostgreSQL, Redis).
  - **Aether Gateway**: Microservice API Gateway & Observability Console (Node.js, Express, Docker).
- **Interactive Case Study Modal**: Deep-dive breakdowns for each project showcasing problem statements, architectural solutions, and performance metrics.
- **Project Filter System**: Instant category switching (All, Full-Stack, Web Apps, APIs & Cloud).
- **One-Click Email Copy & Toast**: Instant clipboard copy with animated visual feedback.
- **Responsive & Accessible**: Fully optimized across ultra-wide monitors, laptops, tablets, and smartphones with mobile drawer navigation.
- **Zero Heavy Framework Dependencies**: 100% Vanilla web stack for maximum speed, zero build step overhead, and sub-second page loads.

## 🚀 Quick Start / Local Preview

You can run the portfolio with any local HTTP server:

### Using Python:
```bash
python -m http.server 5173
```
Then visit [http://localhost:5173](http://localhost:5173).

### Using Node / npx:
```bash
npx serve .
```
